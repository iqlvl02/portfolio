# Separated Portfolio Website

## Files
- `index.html` — all page content and sections
- `css/style.css` — custom styling, responsive layout, and animations
- `js/main.js` — mobile navigation, active navigation state, contact form, footer year
- `js/projects.js` — project category filter
- `assets/` — put your own images, resume, and other files here

## Run it
1. Extract the ZIP file.
2. Open the extracted `separated_portfolio` folder in VS Code.
3. Install the **Live Server** extension if you do not have it.
4. Right-click `index.html` and select **Open with Live Server**.

An internet connection is required for Tailwind CDN, Google Fonts, and Material Symbols.

## Personalize before publishing
- Search for `Alex Chen`, `alex.dev`, and replace with your own name/brand.
- Replace `hello@example.com` in `index.html` and `js/main.js` with your real email.
- Replace the generic education/location text with accurate details.
- Update GitHub, LinkedIn, project, and design links.
- Replace the sample projects with your real projects and descriptions.
- The contact form opens the visitor's email app. It does not send messages through a server.
